219 线上事故：前 5 分钟做什么，事后怎么讲 面试官问「讲一次你处理的事故」，想听的不是英雄主义，是你有没有流程。有流程的人讲时间轴，没流程的人讲心情。
220 行为面与心理博弈：自我介绍、离职原因、压力面 技术过了却挂在「为什么离职」，这种事每天都在发生。行为面不考人品，考的是你在压力下说话有没有结构。
221 薪资谈判：总包、锚点与不踩坑 谈薪不是讨价还价，是把信息差补齐。先问清结构，再谈数字——你随口报出的第一个数，会变成对方心里的天花板。
222 简历与项目表达：把 198 篇知识变成故事 简历不是经历清单，是证据清单——每一条都要能被追问三层，且每一层你都答得出。
223 Shell 脚本面试：手写题、健壮性与那些致命坑 set -euo pipefail 不是万能药，$@ 和 $* 差一个引号就能吃掉你的参数——脚本题的分数，全在边界上。
224 Nginx 面试：配置、反向代理与 502 家族 location 的匹配优先级、proxy_pass 的尾斜杠、缓冲与超时——这三处答错，等于说你没调过线上。
225 Git 面试：分支模型、reset 与救火 问 rebase 和 merge 的区别，其实在问「你懂不懂 commit 是快照、分支只是指针」。
226 Linux 内核参数调优：面试爱问的那几个 sysctl somaxconn、tcp_tw_reuse、vm.swappiness——能说清「调了会怎样、什么时候不该调」的人不多。
227 负载均衡：LVS、Nginx、HAProxy 怎么选 四层和七层不是「谁更高级」，是你能拿到什么信息、愿意付多少性能代价。
228 消息队列面试：Kafka 与 RabbitMQ 的必答题 顺序、幂等、积压、丢失——MQ 的所有难题，本质都是「你要哪一种保证，愿意付什么代价」。
229 分布式事务与一致性面试 别一上来就背 2PC/TCC/Saga，先说清你的业务能容忍多久的不一致。
230 限流、熔断、降级：讲清触发条件才算会 能说出「阈值怎么定、触发后走哪条路径、怎么恢复」的人，比会背四种限流算法的人值钱。
231 存储与文件系统面试：ext4、XFS、NFS 与对象存储 面试问「磁盘满了但 du 看不到」，答案是inode、被删未释放、还是挂载点被覆盖——三种都常见。
232 容器安全面试：逃逸、供应链与 RBAC 容器不是安全边界，共享内核这四个字决定了它所有的风险面。
233 云成本与容量：FinOps 面试题 「你怎么省钱」这题的满分答案不是砍机器，是说清哪部分钱花得不值、以及你怎么证明。
234 运维笔试题 30 道：手写命令与排障推演 笔试不只看答案对不对，写出推理过程也能拿分——很多人直接留空，白白丢分。
235 Ansible 与自动化运维：怎么讲才像做过 会写 playbook 不值钱，值钱的是你知道幂等和收敛在哪个环节被破坏。
236 Terraform 与基础设施即代码：state 被改坏了怎么救 terraform apply 谁都会，难的是你知道 state 里存了什么、坏了怎么恢复。
237 日志系统面试：ELK、Loki 与成本这道必答题 日志平台的难题不是收集，是存多久、怎么检索、谁为成本负责。
238 JVM 与 Java 应用排障：运维不用写代码，但得看懂这四个信号 unable to create new native thread 不是堆内存不够——答错这一句就暴露了。
239 数据库运维面试：备份恢复、主从切换与容量治理 问「你们多久备份一次」之后必问的是「恢复演练做过吗，RTO 多少」。
240 中间件面试：API 网关、注册中心与配置中心 这三个组件名字不同，其实在回答同一个问题：东西变了，怎么让所有人知道。
241 服务网格与流量治理面试：Istio 到底解决了什么 说「为了可观测性上 Istio」会被追问：那用 SDK 不行吗。
242 混沌工程与故障演练：怎么证明你的系统真的可靠 「我们做过灾备演练」不算，能说出上次演练发现了什么才叫做过。
243 容量规划与压测：问「多少台够」时在问什么 他嘴里是数字，考的是你怎么得到这个数字、误差在哪。
244 网络安全运维面试：防火墙、安全组、零信任与等保 运维岗的网络安全题，考的是你怎么在不影响业务的前提下把访问收紧。
245 SQL 面试 30 题：从慢查询到窗口函数 运维岗不写业务 SQL，但出报表、查数据、定位慢查询全靠它。
246 AI 运维面试：AIOps 与大模型在运维里的真问题 「用大模型做智能运维」的靠谱答案和忽悠答案只差一句：你有没有可验证的数据。
